## Stack — chosen for performance
- **HTML5 + CSS3 + vanilla JavaScript** — no framework runtime, no build step, no CDN:
  first paint makes zero third-party requests and the whole site is a few KB.
- **PHP only where a server is genuinely required** (form handling on x10hosting);
  on static hosts the form falls back to `mailto:` automatically.
- Outgrowing static (real checkout, accounts, database)? Create a GOAL and let the
  agents scaffold a Node/Express or PHP backend as the next iteration.

## Publish
- **GitHub Pages** — dashboard → SITES → *Publish to GitHub* (needs `github.token` in `data/config.json`).
- **x10hosting (PHP)** — dashboard → SITES → *Publish to x10 host* (needs `x10` user/pass in config);
  uploads to `/htdocs` via FTP so `contact.php` works.

## Customize
- `index.html` — all copy and structure
- `styles.css` — colors (`--accent` variable at the top), spacing
- `app.js` — nav toggle, cart, mailto form
- `contact.php` — **set `$TO` at the top to your email address** before publishing
- `manifest.json` — sha256 of every file (integrity)

## Honest notes
- The cart is front-end only: connect a payment provider (Stripe/PayPal/etc.) to take real money.
- Contact form needs a PHP host (x10hosting) — on static hosts, the form falls back to mail.
